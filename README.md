# CreatorConnect

CreatorConnect is a platform that helps emerging content creators discover brand collaboration opportunities and helps brands find suitable creators.

## Problem Statement

Small and growing content creators struggle to discover relevant brand collaboration opportunities, showcase their work professionally, and manage collaboration applications in one place, while brands struggle to find suitable creators efficiently.

## Users

1. Creators
2. Brands

## Core Features

- Creator Profiles
- Brand Profiles
- Campaign Listings
- Collaboration Applications
- Application Tracking
