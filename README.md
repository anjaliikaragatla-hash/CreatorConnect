# CreatorConnect

## Problem Statement

Small and growing content creators struggle to discover relevant brand collaboration opportunities, showcase their work professionally, and manage collaboration applications in one place. Brands also struggle to efficiently discover creators who match their campaign requirements.

## Goal

Build a platform that connects creators and brands, allowing creators to showcase their profiles and apply for campaigns while enabling brands to discover and collaborate with suitable creators.

## Users

* Creators
* Brands

## Planned Features

* Creator Profiles
* Brand Profiles
* Campaign Listings
* Campaign Applications
* Application Tracking
* AI-Based Brand Matching (Future)

## Tech Stack

* Frontend: React
* Backend: Java Spring Boot
* Database: MySQL
* Version Control: Git & GitHub
